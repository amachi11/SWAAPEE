# SWAAPE

A responsive campus community prototype for Saint Mary’s University, built in one `index.html` file with HTML, CSS, and JavaScript.

## Run locally

Open `index.html` in a modern browser. In Visual Studio Code, you can optionally install the **Live Server** extension and choose **Open with Live Server**. No npm packages or build step are required.

## Logo

Place the original **Swaape Gradient Logo Mockup (1).png** image beside `index.html` and rename it to `swaape-logo.png`. The header crops this image to show the brand symbol. A temporary S mark appears while the image is missing.

## Features

- Campus feed with locally created posts, likes, and saved posts.
- Talent profiles with skills, interests, and availability.
- Skill swaps and local connection requests.
- Campus events with local interest preferences.
- Keyword-based collaborator suggestions and search/category filters.
- Responsive layout with the left-hand navigation.

## Prototype limits

Profiles and events are fictional. Data is saved in this browser’s localStorage. Connections and event interest do not send notifications. Matching uses keyword rules, not a live AI service. University login, moderation, messaging, shared data, and payments are not implemented.
